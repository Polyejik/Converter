# Portfolio Pulse — сценарий показа CEO

Документ для того, кто показывает. Семь минут, без импровизации в опасных местах.

## Запуск контура

Одна команда из корня проекта:

```bash
cd /home/hermes/projects/converter/Portfolio-Pulse
./tools/run_demo.sh --reset
```

Она собирает локальную базу заново, поднимает API и приложение и печатает адрес. Дальше открыть:

```
http://127.0.0.1:8099/index.html          # приложение (демо-контур, работает офлайн)
http://127.0.0.1:8099/index-local.html    # то же приложение + подключение к локальному API
```

Остановить — `Ctrl+C`. Логи: `/tmp/pulse-api.log`, `/tmp/pulse-app.log`.

## Что показывать и в каком порядке

**1. «Обзор» — 2 минуты.** Первый экран отвечает на вопрос «как идут дела», а не «что нажать».
Показать: пульс поступлений, брифинг в три строки, три KPI, блок «Требуют решения».
Сказать: «Один экран — состояние портфеля и то, что требует вашего решения. Никаких отчётов запрашивать не нужно».

**2. «Требуют решения» → карточка проекта — 1 минута.** Показать, что у решения есть ответственный и срок.
Сказать: «Каждое отклонение уже разложено: объект, причина, ответственный, дата».

**3. «Портфель» — 1,5 минуты.** Показать список проектов, фильтр критических, срез по дивизионам и странам.
Здесь уместно нажать «Открыть критические проекты» из «Обзора» — это переход в «Портфель» с уже включённым критическим фильтром.

**4. «Дивизионы» — 1 минута.** Показать три дивизиона, их руководителей и загрузку по компетенциям.
Сказать: «Видно, где людей не хватает и где назревает перегрузка — до того, как это станет срывом срока».

**5. «Персонал» — 1 минута.** Управленческие показатели сверху, «риск перегрузки» отдельным числом.
Реестр ставок — внизу, в отдельном блоке с прокруткой: «Это административная часть, она не мешает управлению».

**6. «Часы и результат» — 30 секунд.** Показать неделю специалиста и черновик, который сохраняется сам.
Сказать: «Заполнение часов — то, что обычно саботируют. Здесь это три действия и черновик».

## Что не нажимать на показе

- **«Сбросить демо»** — стирает изменения на этом устройстве. Спрашивает подтверждение, но лучше не рисковать.
- **«Новый проект»** — открывает рабочий диалог; безопасно, но занимает время. Показывать только если спросят «а завести проект можно?».
- **«Экспорт»** — молча скачивает JSON. Не нажимать при демонстрации с большого экрана: файл уйдёт в загрузки клиента.

## Что честно говорить про состояние

- Данные — **демонстрационный контур** на срезе 31 июля: это образец, а не портфель клиента. В интерфейсе это написано.
- **Серверная часть работает** (база, права, аудит, оптимистичные версии) — проверено на локальном контуре; для боевого размещения нужен ваш аккаунт Cloudflare.
- **Голосовой ввод** написан и вызывает сервер, но модель ещё не подключена — это следующий шаг после размещения.
- Стоимость содержания: локальный контур бесплатный; при размещении — бесплатный тариф Cloudflare, платятся только запросы к модели (примерно $0,006 за минуту записи).

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Экран пустой, данных нет | Перезапустить `./tools/run_demo.sh --reset` |
| Приложение не открывается | Проверить, что скрипт запуска ещё жив (в терминале висит), открыть адрес из его вывода |
| Странные цифры после опытов | «Сбросить демо» (вернёт исходный контур) или перезапуск с `--reset` |
| Нужен офлайн-показ без сервера | Открыть `index.html` файлом прямо из папки — приложение работает без API |
